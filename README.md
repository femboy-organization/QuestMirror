## Overview

SPECTRA is centered on one use case: viewing the image from a Meta Quest 3 headset on a computer display.

## Scope

| Item | Description |
| --- | --- |
| Source device | Meta Quest 3 |
| Output | Computer screen |
| Project type | Desktop utility |

## Current status

This repository is at the concept and documentation stage. It currently contains project documentation only; there is no runnable application, release, or verified setup procedure.
