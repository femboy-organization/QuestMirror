# Security policy

## Supported versions

Security fixes should target the latest available SPECTRA pre-release. Older pre-release builds may not receive fixes.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in a public issue, pull request, or discussion.

1. If GitHub's private vulnerability reporting feature is available on this repository, use it to send the report privately.
2. Otherwise, contact the repository maintainers through the [femboy-organization GitHub page](https://github.com/femboy-organization). Do not post exploit details or sensitive logs publicly.

Include the affected SPECTRA version, the impact you observed, reproduction steps that can be shared safely, and any relevant sanitized logs. Do not include passwords, pairing codes, access tokens, private keys, or personal device/network information.

There is currently no published response-time guarantee. Maintainers will assess reports as time and information allow.
